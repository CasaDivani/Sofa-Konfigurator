# Sofa-Konfigurator

Mobilfreundlicher Sofa-Konfigurator für GitHub Pages.

## Features
- 3D-Sofa konfigurieren (Materialien, Position, Ebenen)
- Deko / Teppiche / Pflanzen als PNG/JPG
- Google Drive Ordner laden (API Key erforderlich)
- Live-Kamera / AR-Ansicht (Sofa über realem Raum)
- Foto mit Sofa im realen Raum aufnehmen
- Export als PNG/JPG
- KI Retusche (Zauberstab): analysiert das Hintergrundfoto (Licht, Farbe, Körnung, Schärfe, Lichtmuster/Baumschatten) und arbeitet das Sofa per Knopfdruck ein, mit Vorher/Nachher-Vergleich und Maßstab-Kalibrierung (läuft komplett im Browser)

## GitHub Pages
1. Repository erstellen
2. Diesen Ordner-Inhalt (index.html, favicon.png, apple-touch-icon.png) hochladen
3. Settings → Pages → Branch main / root aktivieren

## Google Drive
- Ordner öffentlich freigeben
- Google Cloud API Key mit Drive API erstellen
- Key im Konfigurator eintragen
